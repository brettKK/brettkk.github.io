  • 经济基础
    • 微观经济学绪论
      • 微观经济学概述
        • （经济学基础概念、宏观经济学与微观经济学的对比、西方经济学标志性事件）
        • 经济学的含义，研究对象，研究的基本问题
          • 经济学是研究稀缺资源合理配置的社会科学。
          • 研究对象是 经济资源的配置和利用。
          • 基本问题：生产什么及生产多少，如何生产，为谁生产，何时生产。
        • 经济资源的稀缺性
          • 反映了人类欲望的无限性与资源的有限性之间的矛盾。
        • 经济物品
          • 是指人类必须付出代价才能得到的产品或服务，是必须借助生产资料并通过人类加工出来的物品。
          • 数量有限，有用且稀缺的物品。
        • 理性人假定（经济人假定）
          • 理性人所追求的唯一目标是自身经济利益的最大化。 消费者要效用最大化。生产者要利润最大化。
          • 是微观经济学的基本假设前提。
        • 微观经济学与宏观经济学的区别
          • 假定不同。
            • 微观：理性人假设
            • 宏观：市场失灵
          • 对象不同。
            • 微观： 单个经济主体（消费者，企业，某个行业，某个市场）
            • 宏观：整个国民经济
          • 目标不同。
            • 微观：利益最大化。研究单个经济主体利益最大化的行为入手，解决稀缺社会资源的最优配置问题。
            • 宏观：经济增长，充分就业，物价稳定，国际收支平衡等。对宏观经济波动和经济增长作出经济解释。
          • 理论不同。
            • 微观：价格理论（通过研究单个经济单位的经济行为来说明价格机制如何解决社会的稀缺资源配置问题）
            • 宏观：国民收入理论（以整个国民经济为对象，研究经济中的决定因素及规律，来解决失业，通货膨胀，经济波动，国际收支等问题）
          • 方法不同。
            • 微观：个量分析法
            • 宏观：总量分析法
        • 西方经济学的标志性事件
          • 亚当斯密《国富论》1776年，标志着西方经济学的诞生。
            • 将市场在资源配置中的作用比作“看不见的手”。
          • 马歇尔《经济学原理》，标志着微观经济学的诞生。
          • 凯恩斯《通论》， 标志着宏观经济学的诞生。
    • 需求，供给，市场均衡理论
      • 需求
        • 需求的含义：消费者在一定时间内，在各种可能的价格水平下，愿意而且能够购买的该商品的数量。
        • 需求定理。其他条件不变狭，需求量与价格呈反比。
          • 特殊情况。吉芬商品（土豆是生存的刚需，越贵需求量越大），凡勃伦商品（炫耀性商品）越贵越买。
        • 需求数量的变动与需求的变动（区分需求量的变动与需求的变动）
          • 商品自身价格变了，需求量的变动。
          • 商品自身价格不变，因为其他因素（收入，偏好，替代品，互补）导致需求的变动。
        • 影响需求数量变动的因数。
          • 价格，收入，偏好，替代品价格，互补品价格，其他。
      • 供给
        • 供给的含义：生产者在一定时间内在各种可能的价格下愿意而且能够提供出售的该种商品的数量。
        • 影响供给数量变动的因素。
          • 商品价格因素。
          • 非商品价格因素。生产成本、生产技术、生产者预期、其他。
        • 有效供给=生产者愿意出售+有能力提供（生产出来，可供销售）； 需求=消费者愿意买+买得起。
      • 均衡（市场均衡理论）
        • 市场均衡=供给=需求，此时的价格叫均衡价格，此时的数量叫均衡数量
          • 当促销季过后，供给与需求同时下降，则供给曲线和需求曲线同时左移，均衡产量一定减少，均衡价格不确定。
        • 最高限价。最高限价低于均衡价格，短缺。为了保护消费者。房子。
        • 最低限价。最低价格高于均衡价格，过剩（收购过剩的农产品）。为了保护生产者。粮食。
    • 弹性理论（反应灵敏程度）
      • 【弹性公式都是因变量变动百分比 / 自变量变动百分比】。
      • 需求价格弹性
        • 公式 ed = - 需求量的变化百分比除于价格量的变化百分比。【别反了 Q=f(p), 马歇尔画图是可以反过来了。】
        • 类型【四星】
          • 完全无弹性。 价格随便涨，需求量不变。棺材，火葬，救命特效药。
          • 缺乏弹性. 0〈 ed 〈 1，涨价，需求量几乎不怎么降。特点：替代品少，刚需。生活必需品，食盐，粮食。结论：谷贱伤农。
          • 单一弹性。ed=1。几乎不考。
          • 富有弹性。 ed > 1, 价格稍微一涨，需求量降很多。 特点：替代品多，非必需品。奢侈品，旅游。 结论：薄利多销。
          • 完全有弹性。理论模型，几乎不考。
        • 需求价格弹性和厂商销售收入的关系。
          • 富有弹性。总销售收入与价格变动呈反方向变动趋势。薄利多销。价格下降，销量大涨，总收入增加。
          • 缺乏弹性。总销售收入与价格变动呈同向变动趋势。谷贱伤农。粮食大丰收，供给变多，粮价下降，需求量微涨，农民总收入变少。
          • 单一弹性。价格变动不会引起销售收入的变动。
        • 需求价格弹性的影响因素。
          • 商品的可替代性。可替代品越多，需求弹性越大。
          • 商品用途的广泛性。 在其他条件不变的情况下，用途越广，需求弹性越到。（自来水就不是）
          • 商品对消费者生活的重要程度。 生活必须品的需求弹性较小。
          • 消费者调节需求量的时间。时间越长，需求弹性越大。
      • 供给价格弹性（不考）
      • 需求的交叉价格弹性
        • 区分替代品，互补品，无关品。
        • 公式 exy = y的需求量变化/基期 除以 x的价格变化/基期。
        • 类型。exy》0，替代品。exy=0，x和y是无关的商品。 exy《0 互补品 x价格上升，y的需求量下降。
      • 需求的收入弹性
        • 公式 ei = 需求量的变化/除基期 除于 收入的变化/基期。
        • 类型。 ei》1，高档品，收入一涨，买奢侈品得多。 0《ei〈1，收入大涨，米面需求涨一点点， 必需品。ei《0 低挡品，收入越高买得越少例如吉芬商品。。
        • 恩格尔系数及恩格尔定律。衡量经济发展水平。 恩格尔系数=食物支出 除于 家庭消费总支出。 系数越低，越富有。
          • 基尼系数。
          • 洛伦兹曲线
          • 菲利普斯曲线
    • 消费者行为理论
      • 效用的概念和度量
        • 效用是指消费者从商品消费中得到的满意程度。
        • 效用有两种度量的方法：基数效用论，序数效用论。
        • 基数效用论(三星)
          • 总效用TU， TU=f(Q)
          • 边际效用MU, MU=delta TU / delta Q。
          • 边际效用递减规律。
            • 在一定时期内其他情况不变下，随着消费者对商品的消费量增加，消费者从每一消费单位中得到的效用增量（边际效用）是递减的。
            • 当边际效用MUx为0时，总效用TU达到最大。
        • 序数效用论
          • 偏好的基本假定： 完全性， 可传递性，非饱和性（越多越好，多多益善）。
          • 无差异曲线
            • 表示偏好相同的两个商品的所有组合，能给消费者带来相同的效用水平的轨迹， 横纵坐标都是商品数量。
            • 相同曲线同偏好，不同曲线的效用不同所以不可能相交，远离原点的效用更高，效率为负且凸向原点。
            • 商品边际替代率MRS递减规律。
              • 为了保持同等的效用，消费者要增加1单位x1就必须放弃一定数量的x2.
              • 就是无差异曲线的切线绝对值。MRS12 = -delta X2 / delta X1 = MU1/MU2。
              • 所以，维持效用不变下，消费者为得到商品2而放弃商品1的数量是递减的。
          • 预算线
            • 定义：在收入和价格给定下，消费者所能买到的两种商品的各种组合，反映消费者的收入约束了商品的组合。I = P1 · X1 + P2 · X2
            • 预期线的横纵坐标都是x1和x2的数量，根据公式斜率是-P1/P2。
      • 消费者均衡（四星）
        • 基数效用论的消费者均衡
          • 当用1单位货币购买到的边际效用相等（MU1/P1 = MU2/P2=lamda=单位货币的边际效用）时，消费者就从购买的商品中获得了最大效用。否则消费者会接着改变购买量。
        • 序数效用论的消费者均衡
          • 效用最大化在预算线与无差别曲线的切点处。
        • 消费者均衡的条件
          • MUx / MUy = Px / Py。（基数效用论推出来的结果）
          • MRSxy = Px / Py。（序数效用论推出来的结果）
        • 价格-消费曲线PCC
          • 当一种商品的价格，消费者收入不变时，另一种商品的价格变动带来效用最大化均衡点的轨迹。可以推出需求曲线。
        • 收入-消费曲线ICC
          • 当其他不变，收入变化带来效用最大化均衡点的轨迹。 可以推出恩格尔曲线
        • 恩格尔曲线
          • 收入增加，正常品购买数量增加，收入到达一定值后在增加，劣等品数量减少。
        • 替代效应与收入效应。
          • 商品价格变动引起的商品需求量变动的总效用，拆分了替代效应和收入效应两部分。
          • 收入效应、替代效应与需求曲线的关系。
            • 对于正常品，替代效应，收入效应，总效应与价格呈反比变动。
            • 对于抵挡品，替代效应与价格反向，收入效应与价格同向。
            • 不同类型商品的需求曲线。正常品需求曲线向右下方倾斜。抵挡品需求曲线更陡峭，对价格更敏感。
        • 消费者剩余（两星），买商品时愿意支付的最高价格与实际支付的价格的差额。分析社会福利问题。
    • 生产理论（研究生产者行为，供给的角度）
      • 总产量，平均产量，边际产量，规模报酬
      • 厂商与生产的概念
        • 生产要素是 劳动，资本，土地，企业家才能。
        • 生产函数：生产要素的数量与最大产量的关系函数。
        • 生产的短期与长期：长期是可以调整全部生产要素的时间周期，短期是至少固定一种生产要素投入的数量。
      • 短期生产函数
        • 总产量TPl，平均产量APl，边际产量MPl【增加一单位劳动要素后增加的产量】的关系【四星】
        • 平均产量与边际产量的关系，总产量与边际产量的关系
        • 边际报酬（产量）递减规律：边际产量MPl刚开始增加，之后降低。
        • 生产的三个阶段
          • 第一阶段，MPl》APl，平均产量不断增加，达到最大值，此时增加投入量，可以增加总产量。
          • 第二阶段，MPl与APl相等时APl到达max以后，平均产量和边际产量都在减少，但总产量提高，最优决策空间。
          • 第三阶段，MPl等于0，TPl达到max，此后总产量减少。
      • 长期生产函数
        • 等产量曲线（产量Q不变，K和L变）与边际技术替代率。 MRTSlk = -delta k / delta L = MPl / MPk， 就是等产量曲线上lk点出的斜率绝对值。
        • 规模报酬的变化（三星）， 递增，递减，不变。
          • 规模报酬递增是指产量的增加比例大于各种生产要素的增加比例。不变是增量相同。例如当规模报酬不变时，增加20%的劳动量，保持资本不变，那总产量增加小于20%。
          • 边际收益递减（短期）和规模报酬（长期）递减，两者无因果关系。
    • 成本理论（供给的角度）
      • 成本与生产者均衡
        • 成本与利润
          • 机会成本（放弃的最大收入）
          • 显性成本（会计成本），是实际支付的货币。
          • 隐形成本，厂商自己所拥有且用于了生产的成本。
          • 经济成本 = 显性成本 + 隐形成本。
          • 沉没成本，已经支付而且无法收回的成本。
          • 会计利润 = 总收益 - 会计成本 = 总收益 - 显性成本。
          • 经济利润（超额利润） = 总收益 - 总成本 = 总收益 - 显性成本 - 隐形成本。
          • 正常利润，是指支付给企业家的报酬，属于隐形成本、归到 经济成本。
        • 生产者均衡（两星）。等成本下的最大产量。
          • 等成本线： C=wL + rK。 与等产量曲线相切。
          • 边际技术替代率 = MRTSlk = -dk / dl = MPl / MPk（等产量曲线推到） = w/r（等成本直线）。
          • 生产者均衡的条件是指边际技术替代率 = 两要素的价格比。
      • 成本C函数(总成本与产量之间的关系)及曲线
        • 短期成本函数（两星）
          • STC=TFC（固定成本）+TVC（可变成本）
          • AC（平均成本）=TC/Q = AFC（平均固定成本） + AVC（平均可变成本）。
          • 边际成本MC，成本与产量的斜率， MC=d（TVC）/dQ = w·dL/dQ = w/MP。 边际产量（MP）与边际成本（MC）呈反比。边际产量的最大值对应着边际成本的最小值。
        • 长期成本函数与规模经济（两星）
          • 外在经济：外在条件变好，导致LAC下降。
          • 外在不经济。 外在看行业，导致LAC上移。
          • 长期生产的规模经济和规模不经济的作用决定了LAC曲线的先下降后上升的U型特征。
          • 外部不经济（交易之外带来坏处）：私人成本小于社会成本。社会成本 = 私人成本 + 外部成本（排污水带来的代价）。
          • 外部经济：私人收益《社会收益。

        • 收益曲线。 完全竞争企业的需求曲线是直线（价格不变， 以产品的均衡价格出售），所以平均收益AR和边际收益MR，需求曲线是同一条线。
        • 边际收益（增加一单位产品得到的收益的增加量）MR = d TR / dQ= d(PQ)/dQ = P（1 - 1/ed）。

      • y（收入） = E（支出） = c（消费） + i（投资）, c（消费函数） = a + b（边际消费倾向）y, i（投资函数） = e - d（投资对利率的敏感系数）r,
      • y（收入） = c（消费） + s（储蓄）。（暂时不用，替换y）
      • 产品市场实现均衡的求解（当收入Y=支出E， 则i（投资）=s（储蓄））：y = x - d/（1-b）r。
      • IS曲线是产品市场实现均衡时，r与y呈负相关的直线。
        • b越大，d越大，收入受到利率更敏感，IS曲线越平坦。
        • 移动： 扩张财政政策，y增大，IS向右上方移动。 紧缩财政政策，y减少，IS向左下方移动。
    • 货币市场均衡与LM曲线
      • 凯恩斯认为： 利率不是由储蓄和投资决定的，由货币的供应量（m国家控制）和需求量决定的。
      • 货币的需求： 交易动机，预防性动机（l=ky）k就是货币需求对收入的敏感系数，投机投机（l=-hr）h就是货币需求对利率的敏感系数。L = ky-hr
      • 平衡时m=ky-hr。LM曲线收到k和h的影响。
      • 萧条区域（水平），r极低，货币投机需求成水平线，货币政策无效。
      • 中间区域（斜线），上升。
      • 古典区域（垂直）， r很高，货币投机需求趋于零， LM垂直 y固定。
    • 流动性陷阱（凯恩斯陷阱）。 利率极低，投机动机（有价证券）极高，无论增加多少货币人们不买有价证券把钱留在手中，货币失去流动性，货币政策失效。
    • IS-LM模型。
      • IS曲线与LM曲线交点处实现产品市场和货币市场的共同均衡。

  • 货币与货币制度

    • 货币的职能5个【五星】：
      • 最基本的2个职能：价值尺度（商品的标价）、流动手段（一收钱一手货）。

    • 货币层次【五星】（M0， M1， M2）
      • 以流动性作为货币层次划分的标准, 流动性（资产、负债的流动性）是金融资产能够及时转变为现实购买力，而不使得持有人蒙受损失。
      • M0 = 流通于银行体系之外的现金。
      • 狭义货币M1 = M0 + 单位活期存款 + 个人活期存款。代表国家中的现实购买力。
      • 广义货币M2 = M1 + 准货币（定期存款，外币存款，信托存款，保证金）。代表直接购买力，包含了现实购买力和潜在购买力
      • M3 = M2 + 金融债券 + 商业票据 + 大额可转让定期存单。是金融创新的产物。
    • 货币制度
      • 规定货币的材料（货币制度中最基本，最重要的内容）。货币名称，单位（元）。

        • 本位币是主币。两个特点： 无限法偿能力，可以自由铸造。
        • 辅币是本位币单位以下的小额货币，供找零之用，一般不足值货币。
      • 有限法偿和无限法偿。无限法偿是不能拒收。
    • 货币制度的演变
      • 银本位制，以白银为本位货币的制度。
      • 金银复本位制
        • 平行本位制下，金银兑换比率完全由市场比价决定。
        • 双本位制，国家规定的比价与市场的同时存在。 格雷欣法则-劣币逐良币现象。
        • 跛行本位制，法定比价，金银同为本位货币，政府规定只有金币可以自由铸造，是金银复本位制过渡到金本位制的过渡阶段。
      • 金本位制
        • 金币本位制，最典型的金本位制，可以看到黄金。主币可以自由铸造和溶化。
        • 金块本位制，也叫生金本位制，国内不准铸造、市面上不流通黄金，流通银行券去兑黄金。
        • 金汇兑本位制，也叫虚金本位制，只有纸币在流通，银行券先兑换外汇，外汇可以兑换黄金。最典型的就是布雷顿森林体系。
      • 不兑现的信用本位制， 纸币为本位货币，法律强制流通。
    • 国际货币体系
      • 国际金本位，第一个国际货币体系，货币汇率决定的基础是铸币平价，就是各国货币的含金量来确定，汇率上下的波动由黄金输送点决定，自发可调整的固定汇率制。
      • 布雷顿森林体系1944年7月1。以怀特计划为基础，以美元为中心的国际货币体系。
        • 成立IMF国际货币基金组织。
        • 特里芬难题。导致体系崩溃。美元信誉与美元作为一种清偿货币之间的矛盾。
        • 人为可调整的固定汇率制

        • 确认了浮动汇率的合法性。体系是无体质的体制，不稳定。
        • 提高特别提款权SDR的地位。

      • 2 古典利率理论。认为利率决定于储蓄（供）与投资（需）的相互作用。利率与实体经济有关，与货币政策无关。都是局部均衡
        • 当储蓄》投资时，利率会下降；储蓄=投资，利率达到均衡水平。

    • 保险的基本原则
      • 保险利益原则【四星】
        • 保险利益是投保人或被保险人对保险标的具有法律上承认的经济利益。不是受益人。
        • 投保人对被保险人不具有保险利益的合同无效。【？,合同终止，中止，解除】
        • 在财产保险与人身保险应用上的区别【两星】
          • 签人身保险合同时，投保人对被保险人无保险利益，则合同无效。
          • 财产保险时，事故发生时被保险人对标的无保险利益，不得向保险人要赔偿保险金。
      • 最大诚信原则
        • 告知：保险人要告知条款，投保人要告知与标的相关的重要信息。
        • 弃权，一方当事人放弃权利。主要对象是保险人。
        • 禁止反言，放弃权利的一方以后不得了重申权利。主要对象是保险人。
      • 损失补偿原则
        • 适用与财产保险， 不适用于人身保险（是给付性原则）。
        • 损失补偿的限度，以实际损失为限，以保险金额为限，以保险利益为限。
        • 损失补偿的方式
          • 第一损失赔偿方式。当损失小于保险金额，赔偿为损失金额；当损失大于保险金额，赔偿为保险金额。
          • 比例责任赔偿方式。
            • 当保险价值（市场上的价值）小于保险金额，赔偿为损失金额；
            • 当保险价值大于保险金额，赔偿=保险金额/保险价值 · 损失金额。
        • 在财产保险实务中的特例，定值保险，重置价值保险。
          • 定值保险。赔偿 = 保险金额 · 损失程度。 （当保险标的的价值下降时，保险金额大于保险价值）。
          • 重置价值保险。重新估价确定损失金额。
        • 派生原则。【两星】。不适用于人身保险。
          • 代位原则（权利代位，保险人对破环保险物品的第三者追责；物上代位）。
            • 不让保险人行使代位求偿的后果是： 保险人可以扣减或者要求返还相应的保险金。
          • 重复保险分摊原则。比例责任，限额责任，顺序责任分摊方式。
      • 近因原则， 不以时间最近的损失原因，而以造成损失的决定性原因。
    • 保险公司经营管理和保险监管
      • 保险公司的经营原则
      • 保险密度： 保险缴费额/人数。
      • 保险深度： 保险缴费额/GDP。
      • 保险费率的厘定
        • 生命表是人寿保险定价的基础。
      • 保险监管
        • 保险监管的三支柱：
          • 市场行为监管
          • 偿付能力监管【核心地位
            • 实际偿付能力（资产与负债的差额），实际资本 = 认可资本 - 认可负债。
            • 偿付能力充足率 = 实际资本/最低资本。
            • 准备金为保险公司的认可负债。无固定期限资本债券为保险公司的核心二级资本。
          • 公司治理结构监管。
    • 财产保险【近5年没有题】
    • 人身保险【近5年没有题】
      • 人数险中的医疗保险，既可以采用约定的给付方式，也可以采用补偿方式。
